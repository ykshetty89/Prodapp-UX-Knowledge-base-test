### Sorting by Postal Code — Worker Heuristic and System Gap
- **Date:** 01 Jun 2026
- **Author:** Prodapp UX team
- **Source:** PDF — Hub Worker Loading UX Research Synthesis
- **Tags:** #sorting #postal-code #heuristic #scan-order #placement

Workers sort parcels by postal code before scanning, but scanning determines the actual truck load placement order. These two steps are currently disconnected — no research participant has articulated an ideal combined flow. A design opportunity exists to sequence or combine sorting and scanning so the placement order emerges naturally from the sort.

### Day Shift vs Night Shift — Different Sorting Mental Models
- **Date:** 01 Jun 2026
- **Author:** Prodapp UX team
- **Source:** PDF — Hub Worker Loading UX Research Synthesis
- **Tags:** #sorting #day-shift #night-shift #mental-model #context #DIP

Night shift focuses on DIP pre-planned loads; day shift focuses on distribution point loading. The Hubworker app does not differentiate between these contexts, presenting the same UI to both. Workers adapt mentally but this causes errors when shifts overlap. Design must provide contextually appropriate sorting task overviews per shift type.

### DPS / Pickup-Point ID Mismatch — Blocks Auto-Matching
- **Date:** 01 Jun 2026
- **Author:** Prodapp UX team
- **Source:** PDF — Hub Worker Loading UX Research Synthesis
- **Tags:** #sorting #DPS #ID-mismatch #glow #backend #auto-match

All DPS and pickup points have a 6-digit ID that cannot be auto-matched to Glow pre-plan IDs. This structural data gap requires backend resolution before UX can solve the matching problem. It currently blocks automatic load validation for non-scannable customers and cannot be resolved through UX alone.
