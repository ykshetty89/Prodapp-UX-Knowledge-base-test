### Pre-loading Eliminates Unnecessary Terminal Return Trips
- **Date:** 01 Jun 2026
- **Author:** Prodapp UX team
- **Source:** PDF — Hub Worker Loading UX Research Synthesis
- **Tags:** #pickup #preloading #terminal #trondheim #driver-hours #depot

At Trondheim, drivers drive the same route every week. Pre-loading could eliminate their need to return to terminal to load, but the system does not currently support this workflow fully, wasting legally constrained driver hours. Hub workers pre-loading on Friday means drivers do not need to work Sundays. Terminals can also run overlapping night/day shifts that cover loading, enabling route optimisation on a prepared, known truck load.
